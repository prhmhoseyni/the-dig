## Props

`Menu` is controlled through `open`, `anchor`, and `onClose`; it positions a portal below the anchor and closes on outside click. `Menu.Item` accepts native `HTMLAttributes<HTMLDivElement>`. The example variables must be consistent (`anchor`, `open`, and a defined close handler).

### `Menu`

| Prop                                                           | Type                  | Default |
| -------------------------------------------------------------- | --------------------- | ------- |
| `anchor` <sup className="text-red-600 text-caption2">\*</sup>  | `HTMLElement \| null` | -       |
| `open` <sup className="text-red-600 text-caption2">\*</sup>    | `boolean`             | -       |
| `onClose` <sup className="text-red-600 text-caption2">\*</sup> | `VoidFunction`        | -       |
| `className`                                                | `string`                             | -           |
| `children`                                                     | `ReactNode`           | -       |
