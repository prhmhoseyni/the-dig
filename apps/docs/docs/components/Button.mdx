## Props

`Button` forwards native button props. Set `type="button"` when using it inside a form unless it should submit. During loading it is disabled and replaces its content with a spinner or `loadingIndicator`; `loadingPosition` controls whether children remain visible.

| Prop        | Type                                                                          | Default                                                                                                         |
| ----------- | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `variant`   | `"contained"` \| `"tinted"` \| `"outlined"`                                   | `"contained"`                                                                                                   |
| `className`                                                | `string`                             | -           |
| `color`     | `"brand"` \| `"info"` \| `"success"` \| `"warning"` \| `"danger"` \| `"gray"` | `"brand"`                                                                                                       |
| `size`      | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"`                                | `"md"`                                                                                                          |
| `isLoading` | `boolean`                                                                     | `false`                                                                                                         |
| Others      | `ButtonHTMLAttributes<HTMLButtonElement>` (e.g. `onClick`, `disabled`, etc.)  | <RedirectLink href="https://developer.mozilla.org/en-US/docs/Web/API/HTMLButtonElement">Document</RedirectLink> |
| `startIcon` | `ReactNode`                                                                     | -                                                                                                       |
| `endIcon` | `ReactNode`                                                                     | -                                                                                                         |
| `loadingIndicator` | `string`                                                                     | `null`                                                                                                         |
| `loadingPosition` |  `"start"` \| `"end"`                                                                     | `null`                                                                                                         |
| `isShowAdornmentLoading` | `boolean`                                                                     | `false`                                                                                                         |
