## Props

Document whether `page` is one-based or zero-based for your integration, and provide an accessible current-page label for the active control.

| Prop                                                            | Type                     | Default |
| --------------------------------------------------------------- | ------------------------ | ------- |
| `total` <sup className="text-red-600 text-caption2">\*</sup>    | `number`                 | -       |
| `page` <sup className="text-red-600 text-caption2">\*</sup>     | `number`                 | -       |
| `onChange` <sup className="text-red-600 text-caption2">\*</sup> | `(page: number) => void` | -       |
| `className`                                                | `string`                             | -           |
